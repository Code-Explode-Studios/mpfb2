# Character Studio 2.0.21 — Experimental Features / HD body

## Location

Blender 4.2+ / target Blender 5.3: **3D Viewport → N → Experimental Features**.
The regular MPFB/Model panel is unchanged; the previously experimental
**Muscularity presets**, **Face photo fit**, and **Foot shape & skin realism**
panels now live in this separate sidebar tab.

## HD body geometry & deformation

1. Select the **unbaked MakeHuman basemesh** in Object Mode.
2. Open **Experimental Features → HD body geometry & deformation**.
3. Choose **Subdivision**: viewport levels 0–6, render levels 0–6. Apply.
   Subdivision does not change the original mesh vertex count, shape-key
   indices, rig weights or existing targets. The generated high-resolution
   surface is a modifier evaluation; it is not a replacement control mesh.
4. For sculptable geometry, choose **Multires sculpt** on a character that
   does not already have our HD Subdivision modifier. Apply with 1–4 levels.
   Multires stores extra sculpt data, and raising its level costs memory.
   Switch modes only after explicitly removing our old HD modifiers.
5. Optional: select a **UV-mapped 16-bit height image** and set strength,
   neutral midpoint and an optional existing vertex group. Press Apply again.
   **The texture must match the body UV layout.** DAZ sole maps require
   remapping/projection and sole masks; this version does not automate them.
6. **Audit rig / modifier stack** checks the armature/deformation stack.
   **Preserve Volume (Blender)** toggles dual-quaternion skinning on the
   current body's Armature modifiers. This setting is **not a guarantee**
   for exported FBX, glTF or Unity rigs.

## Animation design / joint-volume problem

The familiar collapsing elbow/knee, twisted wrist (candy-wrapper) and bulging
joints originate in skinning and mesh topology, not lack of polygons.

* Body shape keys are evaluated on the original mesh **before** modifiers.
* HD subdivision / displacement are positioned **before Armature** so HD
  creases and sculpt detail participate in skeletal deformation. Be aware
  high-density skinning is expensive; other modifiers and rigs should be
  inspected if you have a custom stack.
* Blender's **Preserve Volume** (dual quaternion skinning) improves some
  twisting/bending shapes; it can cause bulges and differs from many game
  engine skinning paths. MPFB can also use multiple Armature modifiers for
  selective volume preservation; test carefully before changing them.
* Truly convincing joints require correct weight paint, good base topology,
  twist support where needed and **pose-driven corrective shape keys**.
  They are **not** automatically generated by this HD implementation.
* Test rigged joints at realistic extremes: wrists twist, elbows 0/90/135°, 
  shoulders raised, hips 90°, knees 0/90/135°, ankle dorsiflexion and toe curl.
  Validate against the target runtime after export.

## Safety and limitations

- Creates only explicitly named MPFB-owned modifiers; does not permanently
  subdivide the original basemesh.
- **Remove HD** asks for confirmation because Multires sculpt layers are
  destroyed if they exist. Undo is enabled, but save a .blend backup first.
- Applying a modified height image to a human with an existing rig/UVs
  is supported; no automatic DAZ morph transfer or anatomical correction yet.
- The earlier experimental foot **Wave** wrinkle shader remains available in
  this build; its realism shortcomings are unchanged. Use photographic
  height maps via the HD workflow, subject to UV remapping.
- Verification here covers syntax, package layout and code-level checks; a
  real Blender 5.3 GUI and animated export pass has not yet been run.
